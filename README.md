# ⚽ Football Quiz Party Hub (6-in-1 Online Multiplayer)

เกมทายฟุตบอลออนไลน์เล่นพร้อมกันกับเพื่อน 6 โหมดในห้องเดียว:
1. 🏟️ **Club Legends Battle** — ทายนักเตะที่เคยค้าแข้งกับสโมสร 5 ลีกใหญ่ยุโรป
2. 📋 **Guess the Starting XI** — ทายผัง 11 ตัวจริงนัดชิงในตำนาน
3. 📊 **Top 10 Football Stats** — ทาย 10 อันดับสถิติลูกหนังระดับโลก
4. 🕵️‍♂️ **Career Path (Who Am I?)** — ทายนักเตะปริศนาจากไทม์ไลน์การย้ายสโมสร
5. ⚡ **Football Trivia Kahoot** — ควิซความรู้ลูกหนัง 4 ตัวเลือกวัดความไว
6. 🔢 **Footy Tic-Tac-Toe 3x3** — ตาราง XO ฟุตบอล 3x3 ชิงช่องเรียง BINGO
